# Style presets

Refresh every 6-12 months. Offer 6-8 of these that plausibly fit the page, not all twelve, plus "Other / mix". Always accompany with a one-line description. Example sites are anchors the user can look up; verify they still match before citing.

| Preset | Signature traits | Typical fit |
|---|---|---|
| Clean minimal SaaS | Generous whitespace, neutral palette, one accent, tight type scale | B2B/B2C SaaS, dev tools |
| Editorial / type-first | Strong grid, expressive type, little chrome, content leads | Media, portfolios, long-form |
| Data-dense utilitarian | Compact rows, small type, visible structure, minimal decoration | Dashboards, pro tools, admin |
| Neubrutalism | Hard borders, offset shadows, loud flat color, raw grid | Indie products, creative brands |
| Glass / spatial depth | Translucency, layered surfaces, soft light; opaque reading zones | Consumer apps, OS-like UIs |
| Soft and friendly | Rounded shapes, pastel or clay depth, warm illustration | Consumer, wellness, education |
| Dark premium / technical | Dark surfaces, restrained gradients, precise type | Dev, AI, security, hardware |
| Playful / illustrative / hand-drawn | Custom marks, texture, character, imperfection | Kids, creative, community |
| Retro / Y2K / nostalgic | Pixel or chrome motifs, playful gradients, cleaner layouts than the originals | Brands wanting personality |
| Corporate trustworthy | Conservative palette, clear hierarchy, proof and credentials | Finance, health, gov, enterprise |
| Luxury / restrained | Large imagery, sparse type, slow rhythm, high contrast | Premium goods, hospitality |
| Brand-led custom | Existing design system governs; critique against that system | Any mature brand |

For what is current vs dated, see `design-trends.md`.
