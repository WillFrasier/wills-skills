# Style presets

Refresh every 6-12 months. Use presets at exploration stage or when the user is unsure or wants a new direction; at high-fidelity, infer the style from the mock instead. Offer only the presets that plausibly fit the page, best first, never all twelve: up to the choice tool's cap (often 4, with "Other" added by the tool), or up to 6 in plain text, plus "Other / mix". Mark your recommendation. Always accompany each with a one-line description. If the user is unsure, recommend one preset or a named blend (e.g. "Editorial headings + data-dense lists") and say why. Examples are anchors the user can look up; they drift as products redesign, so verify one still matches before citing it.

| Preset | Signature traits | Typical fit | Example |
|---|---|---|---|
| Clean minimal SaaS | Generous whitespace, neutral palette, one accent, tight type scale | B2B/B2C SaaS, dev tools | Notion, Cal.com |
| Editorial / type-first | Strong grid, expressive type, little chrome, content leads | Media, portfolios, long-form | Stripe Press, The Pudding |
| Data-dense utilitarian | Compact rows, small type, visible structure, minimal decoration | Dashboards, pro tools, admin | Linear (app), GitHub |
| Neubrutalism | Hard borders, offset shadows, loud flat color, raw grid | Indie products, creative brands | Gumroad |
| Glass / spatial depth | Translucency, layered surfaces, soft light; opaque reading zones | Consumer apps, OS-like UIs | Apple visionOS, Liquid Glass |
| Soft and friendly | Rounded shapes, pastel or clay depth, warm illustration | Consumer, wellness, education | Headspace |
| Dark premium / technical | Dark surfaces, restrained gradients, precise type | Dev, AI, security, hardware | Vercel, Raycast |
| Playful / illustrative / hand-drawn | Custom marks, texture, character, imperfection | Kids, creative, community | Mailchimp |
| Retro / Y2K / nostalgic | Pixel or chrome motifs, playful gradients, cleaner layouts than the originals | Brands wanting personality | Poolsuite |
| Corporate trustworthy | Conservative palette, clear hierarchy, proof and credentials | Finance, health, gov, enterprise | GOV.UK, Mayo Clinic |
| Luxury / restrained | Large imagery, sparse type, slow rhythm, high contrast | Premium goods, hospitality | Aesop |
| Brand-led custom | Existing design system governs; critique against that system | Any mature brand | Shopify Polaris, Atlassian |

For what is current vs dated, see `design-trends.md`.
