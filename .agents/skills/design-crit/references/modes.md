# Modes

## Variants

Several versions of the same screen, and the user must choose or combine.

1. Confirm the brief once; it applies to every variant.
2. Score each variant against the need and the primary action first, craft second. Dismiss variants that fail need fit in one line each.
3. Output:
   - Ranking: best to worst, one line of reasoning each.
   - Keep / kill: which variant to carry forward, and which to drop outright.
   - Steal list: specific elements from losing variants worth moving into the winner.
   - Then a normal Phase 3 critique of the winner only, within the usual budget.
4. If no variant serves the need, say so and propose the direction instead of picking the least bad.

## Re-review

A revised version of a screen already critiqued in this conversation (or with prior findings pasted in).

1. Reuse the confirmed brief; ask only if the user says it changed.
2. Diff against the previous findings, each marked:
   - Resolved: fixed, with a one-line note if the fix introduced a new trade-off.
   - Still open: unchanged or only partly addressed; restate the move.
   - Regressed: something from the Protect list or previously fine that got worse.
3. Add new findings only for things the revision introduced, within the usual budget.
4. Close with a one-line verdict on whether the revision moved the need forward.
