# Test: interview on an obvious page

## Input

"Interview me about the calendar page," with a screenshot of a week-view calendar showing family events with owners.

## Expected behavior

- Opens with 3-5 lines of what it can tell from the page (Calendar archetype, baseline job, key inferences).
- Does NOT ask what the page is for, or whether users need to see upcoming events.
- Asks 3-7 questions, prioritizing trigger, real question, and exit state; uses a choice tool with inferred options, best guess first and marked recommended.
- Produces a draft brief using the template, with confidence and source on every field.
